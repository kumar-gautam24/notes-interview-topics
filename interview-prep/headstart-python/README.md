# Headstart · Python Backend Interview Prep

Prep pack for the Headstart (education CRM) Python backend client round, built from the screening feedback, the recruiter's question bank and the JD.
Start with [00-start-here.md](00-start-here.md): it maps every JD point and screening question to the file that covers it, and gives a study order.

| File | What's inside |

| [01-dsa-cpp.md](01-dsa-cpp.md) | Coding round in C++: Fibonacci ladder, right-shift, screening problems, likely next ones |
| [02-python-cheatsheet.md](02-python-cheatsheet.md) | Python concepts interviewers probe: mutability, decorators, generators, OOP, exceptions, GIL |
| [03-fastapi-pack.md](03-fastapi-pack.md) | FastAPI internals, auth, errors, versioning, background jobs, performance |

| [05-indexing-deep-dive.md](05-indexing-deep-dive.md) | Database indexing from zero, with a self-quiz |
| [06-fastapi-rapid-fire.md](06-fastapi-rapid-fire.md) | Every FastAPI concept with trade-offs: middleware order, auth placement, CORS, cookies, WebSockets, pagination |
| [07-mock-interview-log.md](07-mock-interview-log.md) | Mock round: every question, score and model answer |
