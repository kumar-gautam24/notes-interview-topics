# AI + Backend

Interview preparation and reference for AI-adjacent backend engineering — the Python/FastAPI,
PostgreSQL, Redis, and distributed-systems core, plus the LLM layer on top of it (agents, MCP,
RAG, pgvector, evaluation, model serving).

| Folder | What's inside |
|--------|---------------|
| [`answers/`](answers) | A 612-question answer bank, 16 documents, Python → system design. Each answer follows *definition → why it exists → how it's implemented → how it fails → trade-off → example*. |
| [`study-pack/`](study-pack) | A 30-day roadmap, the matching question bank, a 29-model cheat sheet, and a hands-on evidence tracker. |

Start with [`answers/README.md`](answers/README.md) for the reading order, or
[`study-pack/01-30-day-roadmap.md`](study-pack/01-30-day-roadmap.md) if you want a schedule.
