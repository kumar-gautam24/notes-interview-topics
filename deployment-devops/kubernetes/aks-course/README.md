# Kubernetes: from One Container to AKS

A standalone 11-lesson course: containers → why orchestration → control plane & nodes → Pods →
Deployments → Services → Ingress → config/secrets → AKS → an end-to-end lab shipping `hello-api`
to Azure → a debugging playbook. Every lesson follows the same arc: *the problem → picture it →
how it works → try it → check yourself → where people slip*.
